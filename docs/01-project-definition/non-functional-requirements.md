# Non-Functional Requirements

### RNF-01 — Responsive Design
The portfolio shall adapt to different screen sizes and devices, providing a consistent user experience across desktop, tablet, and mobile devices.

### RNF-02 — Accessibility
The portfolio shall follow web accessibility best practices to ensure that its content and functionality are accessible to users with different needs.

### RNF-03 — Performance
The portfolio shall minimize unnecessary resource usage and optimize loading times to provide a fast and responsive user experience.
