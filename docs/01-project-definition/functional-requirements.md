# Functional Requirements

### RF-01 — Navigation
The user shall be able to navigate between the different sections of the portfolio.

### RF-02 — Language Change
The user shall be able to change the portfolio language between Spanish and English.

### RF-03 — Language Persistence
The application shall remember the language selected by the user between sessions.

### RF-04 — Projects
The user shall be able to view information about the projects and access their corresponding repositories.

### RF-05 — Contact
The user shall be able to access the available contact information, including email and social media profiles.

### RF-06 — Resume
The user shall be able to download the current resume in both Spanish and English.
